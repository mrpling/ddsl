# DDSL TLD Reference for AI Assistants

Use this file when selecting TLDs or domain endings for DDSL.

Rules:
- Do not invent TLDs.
- Use only values listed here, supplied by the user, or found in the full reference files.
- Single-label TLDs may be placed in @tlds={...}.
- Multi-label endings such as co.uk MUST NOT be placed in @tlds={...}.
- Use multi-label endings as separate suffix expressions.

Example:

@expr=[a-z]{4,8}
@tlds={com,net,org}

@expr.@tlds
@expr.co.uk
@expr.it.com
